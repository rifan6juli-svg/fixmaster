## Priority Issues

1. [P1] Satu nama atau email panjang merusak daftar mobile. 390px: /customers 866, /settings/staff 632. Akar: min-width:auto grid dua tingkat. Fix: grid-cols-1 di pembungkus halaman dan daftar kartu, tes E2E scrollWidth dengan nama 100 karakter. Fix belum diuji. Perintah: harden.
2. [P1] Dialog tidak bisa di-scroll. dialog.tsx:64 tanpa max-height. 844x390: Tambah staf 492-572px, top -91, Simpan di y=416-457. Fix: max-h-[calc(100dvh-2rem)] overflow-y-auto. Perintah: harden.
3. [P1] Serah terima password sementara tidak ada. Dialog tertutup, password tidak bisa dilihat lagi, tombol generik Simpan. Fix: state sukses dengan password read-only, Salin, langkah berikutnya; tombol Buat akun dan Reset password. Mengubah AFD F-02. Perintah: onboard.
4. [P1] Layar password: entri buta dan tanpa jalan keluar. S-03 satu input ter-mask; S-02 diam soal lupa password padahal A-17 hanya lewat manusia. Fix: toggle tampilkan password, baris "Lupa password? Minta pemilik toko meresetnya.". Perintah: clarify.
5. [P2] S-11 mengutamakan form daripada riwayat. Riwayat mulai y=642, baris pertama y=726 di 1280x800. Fix: tampilan baca default + Ubah, riwayat di kolom besar mulai 1024px. Perintah: layout.
